# 大连理工大学本科毕业论文格式自动审查工具

依据《大连理工大学大学生毕业设计（论文）规范化要求》及官方模板（2025年5月版）。

## 环境要求

- Python 3.8+（标准库，无需额外安装依赖）
- 已安装 Claude Code（可选，用于 `/dut-format-check` 命令）

## 快速使用

```bash
python dut_format_checker.py 论文.docx
```

省略路径时自动查找当前目录中的第一个 `.docx` 文件：

```bash
python dut_format_checker.py
```

## 检查项一览

| 类别 | 检查内容 | 说明 |
|------|----------|------|
| 页面设置 | 纸张大小、四边页边距 | A4；上3.5/下2.5/左2.5/右2.5 cm |
| 正文样式 | 字号、行距 | 小四(12pt)；1.25倍行距 |
| 标题样式 | 1-3级字体、字号、行距 | 黑体；小三/四号/小四；≥1.5倍 |
| 论文结构 | 必要章节是否存在 | 摘要、Abstract、目录、绪论、参考文献、致谢等 |
| 字数 | 正文总字数 | ≥20,000字 |
| 封面 | 题目字数 | ≤25个汉字 |
| 图表编号 | 格式是否为 X.X | 如"图3.1"，不允许"图3-1" |
| 章节编号 | 各级标题数量与格式 | 检测跳号、格式不规范 |
| 参考文献 | 数量、[n]编号、中英文分布、格式标注 | ≥15篇，期刊≥5篇，含英文及近五年文献 |
| 摘要 | 中英文摘要、关键词 | 关键词3-8个 |
| 页眉页脚 | 页眉页脚文件是否存在 | |

## 输出说明

```
【✗ 必须修改】   — 明确违反规范，提交前必须改
【△ 建议修改】   — 可能有问题，建议人工确认
【✓ 已通过】     — 自动检查通过
【需人工核对】   — 程序无法自动判断，打印前逐项确认
```

## 已知局限

1. **页边距**：取文档第二节的边距（跳过封面节）。若文档有超过两个节且各节边距不同，可能取错节，需人工核对。
2. **参考文献编号**：支持两种格式——显式文本 `[1] 作者...` 和 Word 自动列表编号（numPr）。使用 Word 自动编号时脚本会提示"Word自动列表编号，建议人工确认"。
3. **字体核对**：样式字体从 `styles.xml` 读取，正文中局部手动改字体无法检测，需人工抽查。
4. **图表题注位置**（图下表上）、**首行缩进**、**三线表**等视觉格式无法自动检查，见报告末尾人工核对清单。

## 配合 Claude Code 使用

将本目录下的 `.claude/commands/dut-format-check.md` 放入项目的 `.claude/commands/` 目录，即可在 Claude Code 中使用 `/dut-format-check` 命令：

```
/dut-format-check 论文.docx
```

命令会自动运行脚本、补充深度文本分析，并输出完整三级问题报告。

## 大连理工格式速查

| 项目 | 标准 |
|------|------|
| 纸张 | A4，210×297 mm |
| 页边距 | 上3.5 / 下2.5 / 左2.5 / 右2.5 cm |
| 正文字号 | 小四（12pt），中文宋体，英文 Times New Roman |
| 正文行距 | 多倍行距1.25，段前段后0 |
| 首行缩进 | 2字符（不可用空格代替） |
| 一级标题 | 黑体小三（15pt），**居左**，1.5倍行距，段后11磅 |
| 二级标题 | 黑体四号（14pt），居左，1.5倍行距，段前0.5行 |
| 三级标题 | 黑体小四（12pt），居左，1.5倍行距，段前0.5行 |
| 页眉 | 论文中文题目，宋体五号，居中 |
| 页码 | 宋体小五，居中，页脚底部；正文从第1页起 |
| 图编号 | 图X.X（如图3.1），题注在图下，宋体五号居中 |
| 表编号 | 表X.X（如表3.1），题注在表上，宋体五号居中 |
| 公式编号 | (章号.序号)，行末右对齐，公式居中 |
| 参考文献 | GB/T 7714-2015，[n]顺序编号，宋体五号 |
| 参考文献数量 | ≥15篇，期刊≥5篇，含英文和近五年文献 |
| 论文字数 | 正文≥20,000字，≥30页 |
| 摘要 | ≥300字，限一页，关键词3-5个 |
| 打印 | 封面/声明/摘要单面；目录/正文/致谢双面 |
