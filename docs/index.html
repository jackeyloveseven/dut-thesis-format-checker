快速上手
使用方法
纯 Python 标准库，Python 3.8+ 即可，无需 pip install
1

下载脚本

克隆仓库或下载 zip，取出 dut_format_checker.py

git clone https://github.com/jackeyloveseven/dut-thesis-format-checker.git
2

运行审查

将脚本和论文放同一目录，或传完整路径

# 终端输出报告
python dut_format_checker.py 论文.docx

# 同时生成可视化 HTML 报告（双击浏览器打开）
python dut_format_checker.py 论文.docx --html

# 省略路径自动查找当前目录第一个 .docx
python dut_format_checker.py
3

查看报告

终端报告按"必须修改 → 建议核对 → 已通过 → 人工核查"排列。加 --html 后在论文同目录生成 论文名_格式报告.html，带进度环、可折叠分组、可勾选核查清单。

配合 Claude Code 使用（可选）

将 .claude/commands/dut-format-check.md 放入项目的 .claude/commands/ 目录后，Claude 会在脚本报告基础上追加深度文本分析：图表引用一致性、参考文献正文引用完整性、各章本章小结、标题跳号、中英文关键词匹配。

  1. 拷贝 .claude/commands/dut-format-check.md 到项目的 .claude/commands/
  2. 在 Claude Code 中输入 /dut-format-check 论文.docx
  3. Claude 自动运行脚本 + 补充分析，输出完整三级报告

格式速查表
依据官方模板（2026年5月更新版）
项目标准
纸张A4，210×297 mm
页边距上 3.5 / 下 2.5 / 左 2.5 / 右 2.5 cm
正文字号小四（12pt），中文宋体，英文 Times New Roman
正文行距多倍行距 1.25，段前段后 0
首行缩进2字符（不可用空格代替）
一级标题黑体小三（15pt），居左，1.5倍行距，段后11磅
二级标题黑体四号（14pt），居左，1.5倍行距，段前0.5行
三级标题黑体小四（12pt），居左，1.5倍行距，段前0.5行
页眉论文中文题目，宋体五号，居中
页码宋体小五，居中，页脚底部；正文从第1页起
图编号图X.X（如图3.1），题注在图下，宋体五号居中
表编号表X.X（如表3.1），题注在表上，宋体五号居中
公式编号(章号.序号)，行末右对齐，公式居中
参考文献GB/T 7714-2015，[n]顺序编号，宋体五号
参考文献数量≥15篇，期刊≥5篇，含英文和近五年文献
论文字数正文 ≥ 20,000字，≥ 30页
摘要≥300字，限一页，关键词3-5个
打印封面/声明/摘要单面；目录/正文/致谢双面
注意事项
已知局限
以下情形脚本无法完全自动判断，需人工核对
⚠页边距多节文档：自动跳过封面节取正文节，若文档有3+节且各节边距不同，可能取错节
⚠参考文献自动编号：Word numPr 自动编号的 [n] 不写入文本流，脚本通过 XML 属性识别并提示，建议目视确认
⚠局部手动改字体：字体检查基于 styles.xml，正文中手动改格式的段落无法检测，需人工抽查
⚠视觉格式：首行缩进、图题位置、三线表、手写签字等无法自动检查，见报告末尾人工核对清单
