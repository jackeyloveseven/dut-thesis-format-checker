# 大连理工大学本科毕业论文格式审查

依据《大连理工大学大学生毕业设计（论文）规范化要求》对论文进行**严格格式审查**，输出必须修改、建议修改、人工核对三级问题清单。

## 使用方式

```text
/dut-format-check [论文.docx路径]
```

路径省略时自动查找当前目录中的 .docx 文件。

---

## 执行步骤

### 第一步：运行自动检查脚本

```bash
D:\software\miniconda\python.exe dut_format_checker.py $ARGUMENTS
```

若 `$ARGUMENTS` 为空则不传参数：

```bash
D:\software\miniconda\python.exe dut_format_checker.py
```

完整输出报告给用户，不截断。

---

### 第二步：补充深度文本分析

脚本输出后，对提取的论文文本（`_extracted.txt`，不存在则先提取）做以下补充检查，把发现的问题追加到报告末尾。

**提取文本（若 _extracted.txt 不存在）：**

```python
import zipfile, xml.etree.ElementTree as ET, sys
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
ns = 'http://schemas.openxmlformats.org/wordprocessingml/2006/main'
docx = "$ARGUMENTS"
with zipfile.ZipFile(docx) as z:
    with z.open('word/document.xml') as f:
        root = ET.parse(f).getroot()
texts = []
for p in root.iter(f'{{{ns}}}p'):
    t = ''.join(x.text or '' for x in p.iter(f'{{{ns}}}t')).strip()
    if t:
        texts.append(t)
with open('_extracted.txt', 'w', encoding='utf-8') as out:
    out.write('\n'.join(texts))
```

**补充检查项：**

#### A. 图表引用一致性

- 正则找正文中所有 `图\d+[.]\d+` 和 `表\d+[.]\d+` 编号
- 找题注行（"图X.X"或"表X.X"开头的独立行）的编号集合
- 报告：正文引用了但无对应题注的编号；有题注但正文未引用的编号

#### B. 参考文献引用完整性

- 找正文中所有 `[数字]` 引用（含 `[1-5]`、`[2,3]` 范围写法），展开为编号集合
- 对照参考文献列表编号集合
- 报告：正文引用了但列表中不存在的编号；列表中有但正文未引用的孤立文献

#### C. 各章本章小结

- 检查第2章起每章末尾是否有"本章小结"节（绪论除外）
- 逐章报告缺失情况

#### D. 标题编号连续性

- 提取各级标题编号，检查是否连续无跳号（如 2.1 后直接出现 2.3）
- 报告跳号位置

#### E. 中英文关键词数量匹配

- 提取中文关键词数量（按"；"分隔）和英文关键词数量
- 若数量不一致，报告

### 第三步：输出完整审查报告

```text
═══════════════════════════════════════════════════════════════
  大连理工大学本科毕业论文  格式审查完整报告
  文件：[文件名]   审查时间：[当前时间]
═══════════════════════════════════════════════════════════════

【自动检查结果】
（脚本输出原样粘贴）

【深度文本分析补充问题】
A. 图表引用一致性：...
B. 参考文献引用完整性：...
C. 各章本章小结：...
D. 标题编号连续性：...
E. 关键词数量：...

【需人工核对清单】
□ 正文字体：随机抽取3处，右键"字体"确认中文宋体12pt、英文Times New Roman 12pt
□ 行距：右键"段落"确认多倍行距1.25，段前段后0
□ 首行缩进：每段首行缩进2字符（不可用空格代替）
□ 一级标题居左（黑体小三，非居中）
□ 图题在图下，表题在表上，五号宋体居中
□ 页眉：论文中文题目，宋体五号居中（封面/声明页无页眉）
□ 页码：正文从第1页起阿拉伯数字居中；摘要/目录用罗马数字
□ 打印：封面/声明/摘要单面；目录/正文/致谢双面
□ 原创性声明、使用授权声明：手写签字，日期已填
□ 修改记录：四项内容已填写，查重重复比已填入
□ 三线表：无竖线，只有顶线、栏目线、底线
□ 公式编号：(章号.序号) 居中+右对齐
□ 参考文献若使用Word自动列表编号：人工确认显示为[1][2]…格式
□ 外文翻译（原文+译文）已准备

═══════════════════════════════════════════════════════════════
总结：必须修改 X 项，建议核对 X 项，人工核查 X 项
═══════════════════════════════════════════════════════════════
```

## 大连理工格式速查

| 项目 | 标准 |
| ---- | ---- |
| 纸张 | A4，210×297 mm |
| 页边距 | 上3.5 / 下2.5 / 左2.5 / 右2.5 cm |
| 正文字号 | 小四（12pt），中文宋体，英文 Times New Roman |
| 正文行距 | 多倍行距1.25，段前段后0 |
| 首行缩进 | 2字符 |
| 一级标题 | 黑体小三（15pt），**居左**，1.5倍行距，段后11磅 |
| 二级标题 | 黑体四号（14pt），居左，1.5倍行距，段前0.5行 |
| 三级标题 | 黑体小四（12pt），居左，1.5倍行距，段前0.5行 |
| 页眉 | 论文中文题目，宋体五号，居中 |
| 页码 | 宋体小五，居中，页脚底部；正文起第1页 |
| 图编号 | 图X.X（如图3.1），题注在图下，宋体五号居中 |
| 表编号 | 表X.X（如表3.1），题注在表上，宋体五号居中 |
| 公式编号 | (章号.序号)，行末右对齐，公式居中 |
| 参考文献 | GB/T 7714-2015，[n]顺序编号，宋体五号 |
| 参考文献数量 | ≥15篇，期刊≥5篇，含英文和近五年文献 |
| 论文字数 | 正文≥20,000字，≥30页 |
| 摘要 | ≥300字，限一页，关键词3-5个 |
| 打印 | 封面/声明/摘要单面；目录/正文/致谢双面 |
